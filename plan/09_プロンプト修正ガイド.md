## 4. 未決事項・確認事項が決まったときの反映手順
1. `01_決定事項と仮決め一覧.md` の該当する行（U-xx、Q-xx、K-xx）を直す。
   - 「状態」を「確定」にし、決まった日付と内容を書く。
   - 決まったことは、§1 の確定事項に移してよい。
2. §3 の影響箇所マップに従って、計画書（実装の後なら docs）を直す。
3. 設定値だけで済むもの（U-01、U-05、U-10 の一部、U-11 など）は、設定シートの値を変える手順を、history に書く。
4. 実装済みのコードに影響するときは、§2.3 の「不具合を直す」と同じ流れで修正を依頼する。
   - その際、再テストの対象のテストIDを指定する。

**プロンプトの例**
```
plan/01 の U-10（CSVの正式仕様）が決まりました。
内容: 列は「発注先コード, 発注先枝番, 資材コード, 数量, 納期」、ヘッダなし、日付は yyyy/MM/dd。
plan/09 §3 の影響箇所マップに従って、計画書（実装済みなら docs と設定）への反映内容を示してください。
```
