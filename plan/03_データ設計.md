# 03 データ設計

- 版: v1.1（2026/10/31。デザインとコピペ反映の方針を追加）
- スプレッドシート名
  - 本番: `物品購入届DB`
  - 開発: `物品購入届DB_開発`（K-42）
- GAS は、このスプレッドシートに紐づけるコンテナバインドにする（K-02）。

## 1. 共通の方針

- **1行目は見出し**。2行目からデータを入れる。見出しは日本語にする。
- **列の位置で読まない**。プログラムは見出し名で列を探す。
  - 見出しとプログラム用のキー（キャメルケース）の対応は、【Config】 の `COLUMNS` 定数にまとめる。
  - 管理者が列を並べ替えても動くようにする。
- **コード列と日付文字列の列は「書式なしテキスト」（`@`）にする**。
  - 対象: 発注先コード・納入先コード・資材コード・枝番・部署コード・種別コード・数量・納品日・提出日など。
  - 先頭の0や入力値をそのまま残すため。
  - 初期セットアップで設定する（`setNumberFormat('@')`）。
  - 書き込むときも `String()` で文字列にしてから書く。
- **日時列**は `yyyy/MM/dd HH:mm:ss` の文字列で保存する（タイムゾーンは Asia/Tokyo）。
- **日付列**（納品日・提出日）は `yyyy/MM/dd` の文字列で保存する。
- **真偽値**は `TRUE` / `FALSE`（チェックボックスは使わない）で保存する。
- **操作者を表す列**（作成者・更新者・承認実施者など）には、社員ID（メールアドレス）を保存する。画面に出すときは、社員マスタで氏名に直す。
  - 例外: 入力者名・承認者名は、届出の時点の氏名を控えとして保存する。

## 4. マスタ取込の元データと規則

取込は `IMPORT_FOLDER_ID` のフォルダに置いたCSVを読む（構 L126）。文字コードはファイル名で判定する（K-19）。

| 元ファイル | 文字コード | 改行 | データ件数（2026/10時点） | 取込先 | 方式 |

### 4.1 共通の規則
- CSVは `Utilities.parseCsv()` で読む（セル内改行に対応しているため）。行単位で分割してはいけない。
  - 取込後の件数が上の表と一致するかを、フェーズ2で確認する。
- CP932 の読み込みは `blob.getDataAsString('MS932')` を基本にする。
  - 機種依存文字（①、髙など）が化けたら、`'Windows-31J'` を試す。
  - どちらを使ったかを docs/04 に記録する。
- コードは文字列のまま扱う。先頭の0を落とさない。
- 書き込みは `setValues()` でまとめて行う。1行ずつ書かない。
- 取込が終わったら、操作ログに「マスタ取込」を残す（詳細JSONに件数とファイル名）。関係するキャッシュも消す。

### 4.2 発注先マスタ（U-01、K-38）
1. 取引先マスター.csv を読む。
2. 主キー（取引先コード＋枝番）で、既存の行と突き合わせる。
3. **既存の行**: 名称・カナ・略称・科目名2・取込日時だけを更新する。「表示」は変えない。
4. **新しい行**: 科目名2から全角・半角のスペースを除き、`SUPPLIER_VISIBLE_ACCOUNTS` のどれかと一致したら「表示=TRUE」で追加する。
5. **CSVに無くなった行**: 「表示=FALSE」にする（過去の届出が参照しているため、行は消さない）。

### 4.3 社員マスタ（K-38）
1. 365User.csv を読む。`mail` が空の行は飛ばす。
2. 社員IDで突き合わせ、氏名・メール・部・課・役職・有効・取込日時を更新する。
3. 既定部署コードを、課の名前と部署マスタの部署名が一致する部署コードで設定する。
   - 一致しなければ、既存の値を残す。
   - 部署マスタを社員マスタより先に作っておく。
4. CSVに無くなった社員は「有効=FALSE」にする。

### 4.4 部署マスタ・種別マスタの生成（構 L118-119）
1. 資材マスタを取り込んだ後、資材マスタの DepartmentCode / DepartmentName と、MaterialType / 資材種別名の組み合わせを、重複なしで取り出す。
2. 既存の行にあるコードは、名称だけを更新する。有効・表示順・共通部署コードは残す。
3. 新しいコードは「有効=FALSE」で追加する。
4. 部署マスタの「部」は、社員マスタの「課→部」の対応から補う（社員マスタが空なら空のまま）。

## 5. ドライブの構成（構 L105-109）

```
物品購入届/                  ← オーナーのマイドライブ。誰とも共有しない
├── 添付書類/                ← ATTACHMENT_FOLDER_ID
```
