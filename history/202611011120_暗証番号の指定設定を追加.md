# 202611011120 暗証番号の指定設定を追加

## 概要
- ユーザーの依頼: 開発環境で、暗証番号の設定・変更も確認したい。
- ユーザーの選択
  - 追加する機能: 管理者が番号を指定して設定する（本人による変更は追加しない）
  - 番号の決まり: 発行と同じ桁数（`PIN_LENGTH`）。推測しやすい番号でも設定できる

## 機能（変更内容）
- **マスタ管理タブの「暗証番号の発行」**
  - 「ランダムに発行」と「番号を指定する」を選べるようにした。
  - 指定するときは、番号を確認用と2回入力して「設定する」を押す。
  - 指定した番号は画面に再表示しない。
- **メニュー「暗証番号を発行」**
  - 社員IDの次に、「番号を指定（空欄ならランダム）」の入力を追加した。
- **番号の形式チェック**（`validatePin_`）
  - 数字だけで、桁数は `PIN_LENGTH` と同じ（今は6桁）。全角数字は半角に直す。
  - 123456・111111 のような推測しやすい番号も許可する。
- **操作ログ**: 「指定／ランダム」だけを残す。番号は残さない。
- **自分の番号を変えたとき**: 管理者が自分の暗証番号を変えた場合、その場で認証を解除する。次の操作では新しい番号を求める。
- **local_preview.html**: URL に `auth=1`（自動で認証）と `open=adminpin`（暗証番号タブを開く）を指定できるようにした（画面確認用）。

## デザイン
- 発行画面の説明文の下に余白を足した（`.form-section-title + p.small`）。

## テスト結果（`node tools/run_tests_node.js`、フェイク上）
| 区分 | 結果 |
|------|------|
| pure テスト（TC-AU-09 指定する番号の形式を追加） | 39件 / NG 0 |
| 全体（TC-AU-10 管理者による指定を追加） | 46件 / NG 0 |

TC-AU-10 で確認したこと:
- 指定した番号で認証でき、以前の番号は使えないこと
- 戻り値に番号が含まれず、ログにも残らないこと
- 5桁・英字はエラー、111111 は設定できること
- 空欄ならランダムに発行されること
- 管理者以外は FORBIDDEN になること
