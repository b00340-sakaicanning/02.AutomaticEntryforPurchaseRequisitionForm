# 202610311847 デザイン方針とコピペ反映構成への変更

## 概要
ユーザーから2点の依頼があり、詳細実装計画（plan/ v1.0 → v1.1）に反映した。コードは書いていない。
1. 画面デザインを、`../02.ロッカーキー貸出管理(Gemini)/` の画面と同じテイストにする。
2. clasp を使わない前提にし、コピペで反映しやすい構成にする。

| 論点 | 決定 |

## 実施内容
- **参考アプリの調査**
  - Explore サブエージェントで、参考アプリの `gas_app/css.html`・`index.html`・`js.html` と、`docs/`・`GEMINI.md` を調べた。
  - 調べた内容: CSS 変数、フォント、部品のクラス、寸法、レスポンシブ、ファイル構成。
- **デザイン（D-27、K-44、K-47）**
  - `plan/05` に「§0 デザイン方針」を追加した。内容は次のとおり。
    - CSS 変数（全値）、フォントと Google Fonts の URL、文字サイズ、42px の高さ固定などの寸法
    - 部品とクラスの対応表、アイコン、ステータスの色、レスポンシブ
  - ステータスの色を、参考アプリのパレットに合わせた地（bg）と文字（fg）の組み合わせに変えた（`plan/03` の `STATUS_COLORS`、`plan/04` §1）。
  - 共通部品の関数名を、参考アプリと同じ名前にした（`showToast`、`showCustomConfirm`、`toggleLoading`）。
  - 参考アプリの不備（未定義の CSS 変数など）は写さないと明記した。
- **コピペで反映する構成（D-28〜D-30、K-45、K-46）**
  - `Code.gs` を1ファイルにまとめた。もとの12の .gs ファイルは、13のセクション（【Api】〜【Menu】）に分ける形にした（`plan/02` §2.1）。
  - 計画書の中の `Auth.gs` などの表記は、すべて【Auth】のようなセクションの表記に置き換えた。
  - `plan/02` §3.1 に、GAS エディタへの貼り付け手順の表（本番と開発の違い）を追加した。
  - clasp、`.clasp.json`、`.claspignore` の記載を削除した。デプロイと開発・本番の手順は、コピペの前提に書き直した。
  - `stylesheet.html` / `javascript.html` を `css.html` / `js.html` に改名した（参考アプリと同じ名前）。
  - 完了報告に「GAS エディタへ貼り替えが必要なファイル」を列挙するルールを追加した（README、07）。
- `plan/01` に D-27〜D-30 と K-44〜K-47 を追加し、K-42・K-43 を更新した。
- `plan/09` に、デザインとファイル構成の変更の影響箇所、および「GAS に反映する」プロンプトを追加した。
